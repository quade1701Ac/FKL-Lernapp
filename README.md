# LagerLogik v0.3

Lernapp-Prototyp für die Ausbildung **Fachkraft für Lagerlogistik**.

## Neu in v0.3
- adaptiver Schwachstellenmodus
- Spaced-Repetition-Grundlogik mit Wiederholungsboxen
- dynamische Rechenaufgaben, u. a. Meldebestand, Lagerkennzahlen und Andler-Formel
- Auswertung nach Lernfeld und Themenbereich
- Fortschrittsübernahme aus v0.2
- 12-Fragen-Prüfungssimulation
- erweiterter Fragenpool in allen 12 Lernfeldern

## Lokal starten
1. Node.js 20 oder neuer installieren.
2. Im Projektordner `npm install` ausführen.
3. Danach `npm run dev`.
4. Im Browser `http://localhost:3000` öffnen.

## Nächste sinnvolle Ausbaustufe
Supabase für Login/Cloud-Fortschritt, Adminbereich für Fragen, größere IHK-nahe Fragenbank und optional KI-gestützte Freitextbewertung.
